Télécharger pour Android

Android 8.0 ou plus récent

Ouvre cette page sur ton téléphone Android pour installer l'application.

Installation

  1. Appuie sur Télécharger pour Android.
  2. Ouvre le fichier xyd.apk une fois téléchargé.
  3. Si Android le demande, autorise ton navigateur à installer des applications inconnues.
  4. Si Google Play Protect propose d'analyser l'application, accepte l'analyse, puis appuie sur Installer.
  5. Lance xyd, crée ton compte et c'est parti.

Les mises à jour se font ensuite directement depuis l'application.
